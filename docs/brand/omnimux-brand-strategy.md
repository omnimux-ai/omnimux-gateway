# OmniMux 品牌策略与信息架构

现行定位、主标题与能力边界以 [品牌规范](README.md) 为准。此策略服务于 **「属于你的内容电商团队」（Your Content Commerce Team）** 定位：主叙事是桌面端 Agent 内容电商工作台（发现 → 拆解 → 制作 → 发布 → 复盘），同时支持从商品卖点出发制作广告与带货种草视频，也支持从角色造型与参考视频出发制作角色视频（双入口并存）。

## 1. 用户要完成的任务

跨境与内容电商卖家及创作者希望把商品卖点贯穿每一次出片：用熟悉的 Agent 在桌面端管理商品资产、拆解对标视频的开场钩子与转化结构、生成商品与 AI 角色素材、复刻或编排成片，并按计划排期发布到海外社媒平台。难点是让商品卖点、角色形象、素材输入与对标视频在同一条创作链路中顺畅衔接，而不是让用户去挑选底层模型编号。

## 2. 目标用户

| 用户 | 主要任务 | 价值表达 |
| --- | --- | --- |
| 跨境与内容电商卖家 | 围绕商品卖点拆解对标视频、复刻并排期发布带货短视频 | 一套内容电商系统，让商品卖点贯穿每一次出片 |
| 小型内容电商团队 | 在桌面端复用商品库、AI 角色、多角度参考与画布流程持续出片 | 用熟悉的 Agent 跑通拆解、制作与海外排期 |
| 角色与种草创作者 | 建立固定 AI 角色并结合参考视频创作达人风格内容 | 支持从商品出发，也支持从角色造型与玩法开始 |

用户可以从一件商品、一条对标参考视频起步，也可以不先准备商品、直接从一句角色描述或参考造型起步（桌面工作台与 `/ai-influencer-studio` 角色工作台双入口并存）。技术集成方可以使用现有高级入口，普通用户无需理解底层模型或路由分组。

## 3. 差异与取舍

强调「属于你的内容电商团队」：把商品库、对标拆解、AI 角色与多角度设定图、视频复刻、画布编排与海外排期发布整合进桌面端 Agent 工作台。用真实可核验的插件与工作台能力解释输入与产出，不用供应商数量、最低价或未经验证的竞品短板证明价值。

不承诺无人值守全自动完成选品、外部店铺托管、大陆平台发布、独立封面生成或实时竞品趋势抓取。模型与分组由系统处理，不成为普通用户必须理解的起步条件。

## 4. 产品主线

| 任务 | 展示内容 | 不能推导出的承诺 |
| --- | --- | --- |
| 商品与卖点管理 | 在桌面端商品库（`omnimux-products`）维护商品图与核心卖点，供出片复用 | 自动选品或电商后台库存同步 |
| 对标视频拆解与复刻 | 拆解参考视频钩子、卖点与购买引导，结合商品或角色素材复刻视频 | 任意视频都能完整复制、自动获得素材版权 |
| 建立角色与多角度参考 | 描述或特征生成角色图，从本人成功角色主图生成多角度设定图 | 匿名免费生成、任意张数与格式都受支持、永久完全一致 |
| 画布编排、剪辑与排期发布 | 无限画布（`omnimux-workflow`）、视频剪辑（`omnimux-clip`）与发布中心（`omnimux-publish`）海外平台定时排期 | 大陆平台发布、发布前自动预检或流量销量保证 |

## 5. 双落地页信息架构

| 表面 | 核心叙事与访客认知 |
| --- | --- |
| 官网首页（`omnimux.ai`，桌面端落地页） | 「属于你的内容电商团队」——发现、复刻和裂变电商爆款视频；展示桌面端 Agent 从对标拆解、商品与角色制作、画布编排到海外排期发布的完整工作流，主 CTA 指向桌面端下载（`dl.omnimux.ai`）与工作台 |
| 角色落地页（`/ai-influencer-studio`） | 「让你的角色成为热门视频的主角」——聚焦 AI 角色创建、多角度设定图与参考视频复刻，提供网页端直接体验与创作入口 |

版块和导航的实现依据见 [落地页文案与实现](landing-page-copy.md)。

## 6. 文案与收费

首页标题先讲内容电商视频的发现、复刻与裂变，描述再讲商品卖点与熟悉的 Agent 一站式出片；角色页讲角色与参考视频创作。所有能力表述严格区分「已交付桌面插件/网关能力」与「流程示意」，不把静态示意数据写成实时抓取。

现行计费为 **按次消耗积分（预充值阶梯折扣加量包）**；生产环境中旧订阅套餐已停用（`fork: plans-disabled` / `fork: payg-topup-ladder`），代码保留可选订阅能力但对外主推按需充值按次付费。充值阶梯折扣与账户权益从当前价格区和钱包核验，不在品牌策略硬编码旧套餐名或固定价目。
